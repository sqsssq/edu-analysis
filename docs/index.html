Why this package

Interpretable by construction.

Variables become binary nodes and relationships become explicit fields h and interactions J. Every result carries assumptions, diagnostics, and the preprocessing contract used to produce it.

01 / FIT

Maximum entropy

Match observed moments with an explicit pairwise energy distribution.

02 / INSPECT

Readable parameters

Inspect signed interactions, correlations, energy statistics, and model-internal interventions.

03 / REPRODUCE

Auditable workflows

Record thresholds, missingness, weights, calculation paths, and provenance.

Quickstart

From table to model in minutes.

The core package requires NumPy and PyTorch. Optional extras add PISA readers and Matplotlib visualizations.

pip install interpretable-learning-energy-model
pip install 'interpretable-learning-energy-model[visualization]'
from learning_energy_model import DataConfig, LearningModel

config = DataConfig(
    feature_names=("support", "resources"),
    target_name="outcome",
)
model = LearningModel(config, seed=7)
fit = model.fit_table(table)
analysis = model.analyze()

Visual analysis

Make interactions visible.

Plotting helpers return Matplotlib figure/axes pairs, so they can be composed in notebooks and reports.

from learning_energy_model.visualization import (
    plot_interactions, plot_correlations,
    plot_training_history,
)

analysis = model.analyze()
plot_interactions(analysis, annotate=True)
plot_correlations(analysis)
plot_training_history(model.fit_result)

What the figures mean

J heatmap shows signed interaction strength. Correlation heatmap shows model-implied association. Training history shows the objective over epochs.

Node-freezing outputs are model-internal structural contributions, not causal effects or individualized recommendations.
PISA workflows

Reproduce carefully, locally.

The package supports local, codebook-backed preparation for PISA-style files. Raw PISA data stays outside the repository; reports should contain aggregate parameters, diagnostics, and provenance only.

Paper-aligned core

Binary nodes, exact enumeration up to the configured threshold, and first- through fourth-order moment outputs.

Explicit boundaries

Ordinary row weights are supported. Full complex-survey inference, replicate weights, and plausible-value aggregation are not yet implemented.

Honest comparison

Report data preparation, threshold rule, sampling path, convergence, and deviations from the paper.

Project status

Research package in active development.

The repository includes tests, CI, synthetic recovery benchmarks, local PISA workflows, and optional visualizations.
