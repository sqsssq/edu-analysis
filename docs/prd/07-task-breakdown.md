# Implementation Task Breakdown

## Planned Tasks

These are planned slices, not yet approved execution tasks:

1. Create package metadata and the public API skeleton.
2. Implement binary pairwise energy and exact state enumeration.
3. Implement weighted empirical moments and interpretable moment matching.
4. Implement KL/autodiff training as a cross-check path.
5. Implement conditional prediction and structured result objects.
6. Implement Monte Carlo sampling, multiple chains, and convergence diagnostics.
7. Implement node-freezing analysis and energy/entropy diagnostics.
8. Add synthetic parameter-recovery and exact-vs-sampling tests.
9. Add PISA preparation instructions and reproduction benchmarks without raw data.
10. Add serialization, notebook examples, API docs, and PyPI packaging.

Each task must keep the smallest complete scope and state its numerical verification method.

Each real task should be created under `docs/tasks/` using `docs/tasks/TASK_TEMPLATE.md`.
