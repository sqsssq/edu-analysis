# Feature Design

## Design Position

`Interpretable Learning Energy Model` should not become `an opaque black-box predictor or an irreproducible research script`.

## Core Interaction Loop

```text
Start from the product brief and scientific rules.
-> Implement one verifiable package slice.
-> Run synthetic and numerical verification.
-> Record assumptions and hand off for review.
```

## Feature Principles

- `Prefer interpretable statistics over opaque optimization.`
- `Keep exact computation as the reference path.`
- `Expose uncertainty, assumptions, and limitations.`
